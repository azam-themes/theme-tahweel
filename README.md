## المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| صفحة هبوط مدمجة | صفحة مخصصة لمنتج واحد لزيادة التركيز والمبيعات |
| عدادات تنازلية (FOMO) | خلق إحساس بالاستعجال لدى العميل |
| شارات الثقة والضمان | في كل مكان لتقليل التردد |
| إثبات اجتماعي | قسم مخصص لآراء العملاء |
| نافذة منبثقة ذكية | لجمع الإيميلات مع كود خصم |
| 22 إعداد قابل للتخصيص | ألوان، خطوط، أقسام، وأكثر |
| دعم ثنائي اللغة | عربي + إنجليزي |
| كود نظيف وسريع | بدون مكتبات خارجية ثقيلة |

## بنية الملفات

```
theme-tahweel/
├── twilight.json          # إعدادات الثيم والمكونات
├── package.json           # معلومات المشروع
└── src/
    ├── assets/
    │   ├── js/app.js      # JavaScript
    │   └── styles/app.css # CSS
    ├── locales/
    │   ├── ar.json        # الترجمة العربية
    │   └── en.json        # الترجمة الإنجليزية
    └── views/
        ├── layouts/       # القالب الرئيسي
        ├── components/    # المكونات المشتركة
        └── pages/         # صفحات المتجر
```

## التثبيت والتطوير

```bash
# تثبيت أداة سلة
npm install -g @salla.sa/cli

# تسجيل الدخول
salla login

# تشغيل خادم التطوير
salla theme serve

# نشر الثيم
salla theme publish
```
